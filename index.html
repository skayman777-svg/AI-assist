AI Support Assistant on n8n

The workflow takes a customer question via Webhook, searches the knowledge base, asks an LLM to write the answer, checks confidence and either replies on its own or hands the ticket to a manager. Every request is logged.

Setup

  1. ImportIn n8n: Workflows → Import from File, or paste the JSON onto the canvas.
  2. SettingsIn the “Settings & request” node set the API URL, model, confidence threshold and the manager chat.
  3. KeysCreate credentials: Header Auth for the LLM, Telegram bot, Google Sheets.
  4. Knowledge baseReplace the sample articles in the “Knowledge base search” node with your own, or with a query to Notion / a vector DB.
