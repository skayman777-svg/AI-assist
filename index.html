AI-ассистент поддержки на n8n

Сценарий принимает вопрос клиента через Webhook, ищет ответ в базе знаний, просит LLM сформулировать ответ, проверяет уверенность и либо отвечает сам, либо передаёт обращение менеджеру. Каждое обращение пишется в журнал.

12 стандартных узлов Любой OpenAI-совместимый API Журнал в Google Sheets

Схема сценария

Узлы подсвечиваются, когда вы отправляете сообщение в стенде ниже.

Стенд диалога

Имитация в браузере: поиск по базе знаний и проверка уверенности работают по той же логике, что Code-узлы сценария. Ответ LLM имитируется текстом найденной статьи.

Сценарий пишет такую же строку в Google Sheets (лист «Журнал»), плюс ответ и причину передачи.

Подключение

  1. ИмпортВ n8n: Workflows → Import from File или вставить JSON на холст.
  2. НастройкиВ узле «Настройки и запрос» указать адрес API, модель, порог уверенности и чат менеджера.
  3. КлючиСоздать учётные данные: Header Auth для LLM, Telegram-бот, Google Sheets.
  4. База знанийЗаменить статьи-примеры в узле «Поиск в базе знаний» на свои или на запрос к Notion / векторной базе.
